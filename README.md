# 立法院會議逐字稿

本專案建立並整理立法院會議的逐字稿，目的是提供事實給所有關心的人，原汁原味呈現立法院所有發生的事，不對任何言論作評論。

逐字稿由AI聽寫+人工查核，不保證百分之百正確，如有發現錯誤的地方，歡迎PR修正。

## 什麼? 逐字稿還是沒時間看?

沒關係，我們提供了 <a href="https://miva.bookai.com/?appId=040cf4f0-3957-4c03-830b-86d98b022ef1" target="_blank">立法院的正義 AI 書僮</a> 幫你快速定位自己關心的議題，讓你快速掌握立法/質詢過程的來龍去脈。

## 處理流程
1. 從 <a href="https://www.youtube.com/@legislativeyuan/playlists" target="_blank">立法院 Youtube 頻道</a> 會議影片取出聲音檔
2. 使用 <a href="https://meeting-dev.bookai.com/" target="_blank">Osmi 會議記錄 APP</a> 轉出逐字稿
3. 到 <a href="https://ppg.ly.gov.tw/ppg/" target="_blank">立法院議事暨公報資訊網</a> 查看有無會議相關檔案
4. 將逐字稿、相關檔案上傳到 <a href="https://nabu.bookai.com/" target="_blank">Nabu AI 資料庫</a> 並上架
5. 上架的資料即可在 <a href="https://miva.bookai.com/" target="_blank">Miva AI 書僮</a> 網站與AI對話討論
